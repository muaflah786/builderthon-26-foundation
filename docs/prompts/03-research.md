# 03: Research

```text
Research the following for our hackathon project. Use web search if available.

Project summary: <<1–3 sentences>>
Research questions:
1. <<e.g. existing products/apps solving this, and their gaps>>
2. <<e.g. public APIs or datasets we could use (free tier, auth, rate limits)>>
3. <<e.g. domain facts/rules/standards we must respect>>

Requirements:
- Cite a source (URL) for every factual claim. Say "not found" rather than guessing.
- For each API/dataset: what it provides, cost/free tier, auth method, rate limits,
  data format, terms-of-use restrictions, and whether it needs a server-side key.
  Recommend one, plus a fallback if it fails during the demo (cached/seed data).
- For competitors: 1 line each on what they do well and the gap we can fill.
- Flag anything that is outdated, region-restricted, or needs approval/signup time.
- Finish with a 5-bullet "what this means for our build" summary.

Keep it under 600 words plus the source list.
```
